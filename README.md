# MEME LAB Meta Radar

Read-only research radar for stock-paired/community tokens.

## Versions
- `v0.1` — live discovery + basic normalized table.
- `v0.2` — persistence, snapshots, filters, development score, JSON export.
- `v0.3` — stable test build: proxy server, IndexedDB, adaptive refresh, Data Gate, risk flags, detail panel, debug log, demo/offline mode, tests.

Start with **v0.3**. See `v0.3/README.md`.

This project does not trade, sign transactions, launch tokens, or provide buy/sell recommendations.
